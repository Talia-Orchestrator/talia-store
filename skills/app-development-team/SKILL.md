# Team sviluppo app

Use the team's existing agents for implementation and bug fixes. Select only the
roles needed for the actual task. Give each agent a concrete responsibility and
integrate the result before reporting completion. Read the repository's own
instructions and verify the changed behavior. Prefer Markdown for working
documents; create Office or PDF files only when the user requests them.

The team manifest in `team.json` is Store metadata. It is not an instruction to
install packages from a model response or to bypass the Store review.

# Feishu / Lark CLI per Talia

Questo pacchetto apre la configurazione Feishu/Lark CLI già integrata in Talia.
L’installazione dallo Store salva solo un riferimento dichiarativo: non avvia
processi, non installa la CLI e non autorizza account.

Dopo l’installazione, scegli **Apri connettori** e segui la guida di Talia.
Feishu e Lark condividono la stessa CLI e la stessa scheda di configurazione.
La connessione richiede una versione di Talia che supporti questo pacchetto.

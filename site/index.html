Subscriptions

Not just API. Your subscriptions work too.

Connect providers through your existing account, your own API key, or your local CLI tools — not just pay-per-use.

  • ⌬ Account sign-in (OAuth) Sign into an existing account (e.g. Claude Pro / ChatGPT).
  • ⚷ Your own API key Paste the key you created in the provider's console.
  • ⌖ External CLI — existing account Claude Code, Codex, OpenCode… use the account and settings already configured in that tool.

Not universal or unlimited: each provider's own terms and fees apply.

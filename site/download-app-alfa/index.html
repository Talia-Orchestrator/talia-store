Talia Alfa

Versione sperimentale 0.16.4-alfa.3. Il prompt progressivo è attivo. Al primo avvio l’app usa un profilo separato. Nel menu dell’app scegli Profili → Nuovo profilo… per crearne uno. Dallo stesso menu puoi scegliere Principale / Beta o riaprire un profilo esistente. Quando scegli un profilo diverso, Talia Alfa salva la sessione e si riavvia automaticamente.
